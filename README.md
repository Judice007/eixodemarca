# Eixo de Marca

Site institucional do Eixo de Marca, construído em Next.js/vinext e publicado com OpenAI Sites.

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

## Validação

```bash
pnpm lint
pnpm build
```

A rota principal preserva a experiência imersiva da referência autorizada, com identidade, conteúdo e paleta próprios do Eixo de Marca.
